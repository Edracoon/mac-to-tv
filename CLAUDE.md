# mac-to-tv

Local web UI, served by a Mac, to control a TV on the local network and play videos on it. Start with `README.md`
(what it does, how it is laid out) and `CONTRIBUTING.md` (how TV support is added).

## Agent skills

### Issue tracker

Issues live in GitHub Issues for `Edracoon/mac-to-tv`, via the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Default vocabulary: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `GLOSSARY.md` and `docs/adr/` at the repo root, created when first needed. See `docs/agents/domain.md`.
